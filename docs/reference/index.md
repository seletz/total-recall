# Referenz

Nachschlagewerk: was es gibt, wie es heißt, was es tut. Die Referenz beschreibt den Ist-Zustand und erklärt nicht; das *Warum* steht in den [Erklärungen](../explanation/index.md), das *Wie* in den [How-To-Guides](../how-to/index.md). Alle Beispielausgaben sind erfunden.

In diesem Abschnitt:

- [Befehle](10-befehle.md): jeder Befehl mit Optionen, Ausgabe und JSON.
- [Konfiguration](20-konfiguration.md): die TOML-Datei, alle Schlüssel, Umgebungsvariablen.
- [TUI](30-tui.md): Ansichten, Tasten, Maus, Farben, Grafikmodi.
- [Schema](40-schema.md): Tabellen, Views, `actor` und Zeiten für eigene SQL-Abfragen.
- [Release-Assets](50-release.md): Archive, Checksummen und SBOMs eines Releases und wie man sie prüft.
- [Änderungen](90-aenderungen.md): was sich je Version geändert hat; der Abschnitt eines Tags wird der Kopf der Release Notes auf GitHub.
